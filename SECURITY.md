# Безпека · Security

## Як повідомити про вразливість · Reporting a vulnerability

Будь ласка, не пишіть про вразливість у відкритих issues. Скористайтеся приватним повідомленням: вкладка **Security → Report a vulnerability** у цьому репозиторії.

Please do not report a vulnerability in public issues. Use a private report: **Security → Report a vulnerability** in this repository.

- Відповідь — протягом **3 днів**. · A reply within **3 days**.
- Виправлення серйозної вразливості — протягом **7 днів**, з новим випуском і поясненням у його описі. Решта — у найближчому випуску. · A fix for a serious vulnerability within **7 days**, in a new release with an explanation in its notes. Anything else in the next release.

Підроблені чи пошкоджені дані (сувій, латка, індекс), які застосунок прийняв би, — теж вразливість. · Forged or damaged data (a scroll, a patch, the index) that the app would accept is a vulnerability too.

## Підтримувані версії · Supported versions

Лише остання версія. · Only the latest version.

Потрібен **Android 12** або новіший: старші версії вже не отримують оновлень безпеки, а всі застосунки авторки мають однакову нижню межу. · Requires **Android 12** or newer: older versions no longer get security updates, and all of the author's apps share the same lowest version.
